# Контрольная работа №3

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Краткое описание проекта
Проект представляет собой адаптивную версию многостраничного сайта интернет-магазина игровой периферии (GamingLARP). Работа выполнена на основе проекта из Контрольной работы №1.

## Структура проекта
```text
kr3-responsive-shop/
├── index.html          # Главная страница
├── catalog.html        # Каталог товаров
├── product.html        # Страница товара (с таблицей характеристик)
├── order.html          # Страница оформления заявки (с формой)
├── contacts.html       # Контакты
├── css/
│   ├── style.css       # Базовые стили
│   └── responsive.css  # Адаптивные стили и медиазапросы
├── js/
│   └── main.js         # Логика работы меню, темы и модалок (из КР1)
├── images/             # Изображения
├── lighthouse/         # Отчет/скриншот проверки доступности
├── README.md
└── .gitignore
```
